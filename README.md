# SQL-практика и продуктовая аналитика

Репозиторий с решениями практических задач по SQL в рамках курса **[«Симулятор SQL» от Karpov Courses](https://karpov.courses/simulator-sql)**.

Здесь собраны SQL-запросы, примеры анализа данных и решения продуктовых задач, приближенных к реальной работе аналитика.

Основная цель проекта — закрепить навыки работы с данными, научиться рассчитывать продуктовые метрики, исследовать поведение пользователей и формулировать выводы на основе данных.

## Основные направления

### 1. SQL Practice

Практика написания SQL-запросов и работы с реляционными базами данных:

- Фильтрация, сортировка и агрегация данных;
- Группировка и объединение таблиц (`JOIN`, `UNION`);
- Подзапросы и CTE (`WITH`);
- Оконные функции;
- Работа с датами и временными интервалами;
- Условная логика и обработка данных.

### 2. Product Analytics

Решение практических задач продуктовой аналитики на данных учебных сервисов:

- Расчёт ключевых продуктовых метрик (DAU, WAU, MAU и других);
- Анализ пользовательской активности и динамики метрик;
- Когортный анализ и Retention;
- Анализ привлечения, удержания и оттока пользователей;
- Исследование поведения пользователей и проверка гипотез;
- Анализ выручки, затрат и финансовых показателей;
- Подготовка данных для визуализации и построения дашбордов.
